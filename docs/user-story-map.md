# ユーザーストーリーマップ（USM）

最終更新：2026-11-26 ／ 対象バージョン：1.0.0（`main` ブランチ）

> このファイルは「誰が・何のために・どんな順番で使うか」の全体像です。
> 機能を追加・変更したら、該当するストーリーの状態（✅/🟡/⬜）とリリース欄を更新してください。

## 1. プロダクトの一言

**ラジオの「また聴きたい回」だけをストックし、あとで迷わず聴き返せるようにする個人用 PWA。**
全放送の網羅（聴取ログ）ではなく、リピート候補・お気に入り回の厳選ストックに特化する。

## 2. ペルソナ

| 項目 | 内容 |
| --- | --- |
| 人物像 | 深夜ラジオ・ポッドキャストを日常的に聴くリスナー（開発者本人） |
| 利用環境 | スマホ片手（通勤・就寝前）。radiko / Spotify / Apple Podcasts 等で聴く |
| 困りごと | 「あの神回、いつの放送だっけ？」が思い出せない。出演者やゲストで探したい |
| 制約 | 無料で運用したい。サーバーや有料サービスは使わない。個人情報を外に出したくない |

## 3. 状態の凡例

- ✅ 実装済み（R1 / R2）
- 🟡 一部実装・改善余地あり
- ⬜ 未実装（バックログ）

## 6. バックログ（優先度順の目安）

1. 聴ける場所のリンク（radiko タイムフリー / Spotify / YouTube の URL 欄）
2. メモの全文検索
3. タグ（神回・企画回・ゲスト回 など）と絞り込み
4. 番組の別名（略称）欄 → スキーマ v2（`programs.aliases`）
5. 「聴き返した」記録（聴き返し回数・最終聴取日）
6. 統計（出演者ランキング・月別件数）
7. 無料かつ鍵を公開しない方法でのクラウド同期（例：ユーザー自身の Google Drive を OAuth で利用。要調査）

## 7. やらないと決めたこと

| 案 | 理由 |
| --- | --- |
| 有名番組の初期データ同梱 | 改編ですぐ古くなる。Podcast 候補で代替 |
| Spotify 検索 | API にアプリ登録と秘密鍵が必要。公開リポジトリでは安全に扱えない |
| 指定メールアドレスへの自動送信 | 送信サーバー／外部サービスの鍵が必要で、データが第三者を経由する。共有シートで代替 |
| 下部ナビ6枠化（バックアップ専用タブ） | スマホ幅で押しにくい。ホームのガイド上に配置 |
| 有料サービス・独自ドメイン | 無料運用が前提 |
