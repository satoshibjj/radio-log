最終更新：2026-11-26 ／ 対象バージョン：1.3.0（R4＋番組の手入力、`main` ブランチ）

> このファイルは「誰が・何のために・どんな順番で使うか」の全体像です。改善案の詳細と優先度は [roadmap.md](roadmap.md)。
> 機能を追加・変更したら、該当するストーリーの状態（✅/🟡/⬜）とリリース欄を更新してください。

## 1. プロダクトの一言

**ラジオの「また聴きたい回」だけをストックし、あとで迷わず聴き返せるようにする個人用 PWA。** Podcast・YouTube・配信のアーカイブにも使える。
全放送の網羅（聴取ログ）ではなく、リピート候補・お気に入り回の厳選ストックに特化する。

## 2. ペルソナ

| 項目 | 内容 |
| --- | --- |
| 人物像 | 深夜ラジオ・ポッドキャストを日常的に聴くリスナー（開発者本人） |
| 利用環境 | スマホ片手（通勤・就寝前）。radiko / Spotify / Apple Podcasts / YouTube 等で聴く・見る |
| 困りごと | 「あの神回、いつの放送だっけ？」が思い出せない。出演者やゲストで探したい |
| 制約 | 無料で運用したい。サーバーや有料サービスは使わない。個人情報を外に出したくない |

## 5. リリースの区切り

| リリース | テーマ | 内容 |
| --- | --- | --- |
| R1 | 自分ひとりで「記録して振り返る」 | S1〜S7、IndexedDB 4ストア、PWA、整合性ルール、JSON 入出力 |
| R2 | 手間を減らし、迷わず使える | 入力補助（Podcast候補・放送局チップ・Wikipedia・よく出る人・前回と同じ）、並び替え、おまかせ1本、シェア画像、ホーム画面とガイド、バックアップ導線 |
| R3 | 聴き返すまでつなぐ・対象を広げる | リンク欄・放送日を任意に（スキーマ v2、v1 からの移行と v1/v2 バックアップ両対応）、YouTube 等への文言・配信元チップ、YouTube oEmbed による題名・チャンネル名の取得 |
| R4 | 人とおすすめを交換する | リスト共有（10件まで・リンクの # 以降に圧縮して入れる・メモの有無とプレビュー・ファイル送付・別枠で見て選んで取り込み・厳しい検証）。スキーマ変更なし |
| Backlog | 必要になったら | 下記 3 以降 |

## 6. バックログ（優先度順の目安）

> **次にやること**：決まっていない（★1〜★3 は完了）。以下は保留中の候補。使ってみて必要になったものから選ぶ。詳細は [roadmap.md](roadmap.md)。
> 済：リンク欄・放送日を任意に・ラジオ以外への拡張（R3、スキーマ v2）、リスト共有（R4）。いずれも 2026-11-26。

1. メモの全文検索
2. タグ（神回・企画回・ゲスト回 など）と絞り込み
3. 番組の別名（略称）欄 → スキーマ v3（`programs.aliases`）
4. 「聴き返した」記録（聴き返し回数・最終聴取日）
5. 統計（出演者ランキング・月別件数）
6. 無料かつ鍵を公開しない方法でのクラウド同期（例：ユーザー自身の Google Drive を OAuth で利用。要調査）

## 7. やらないと決めたこと

| 案 | 理由 |
| --- | --- |
| 有名番組の初期データ同梱 | 改編ですぐ古くなる。Podcast 候補で代替 |
| Spotify 検索 | API にアプリ登録と秘密鍵が必要。公開リポジトリでは安全に扱えない |
| YouTube Data API（検索・再生数など） | API キーが必要。題名・チャンネル名はキー不要の oEmbed で取得する |
| アプリ内での動画の埋め込み再生 | 規約・通信・プライバシーの配慮が増える。リンクで各サービスを開く |
| リスト共有用の短縮 URL・保存サーバー | 外部サービスやサーバーにデータを預けることになる。リンクの # 以降に入れ、長いときはファイルで送る |
| 受け取ったリストの自動取り込み | 他人が作ったデータが勝手に入るのを防ぐ。必ず利用者が選んで入れる |
| 指定メールアドレスへの自動送信 | 送信サーバー／外部サービスの鍵が必要で、データが第三者を経由する。共有シートで代替 |
| 下部ナビ6枠化（バックアップ専用タブ） | スマホ幅で押しにくい。ホームのガイド上に配置 |
| 有料サービス・独自ドメイン | 無料運用が前提 |
